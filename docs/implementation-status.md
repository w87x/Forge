# Implementation status

Current milestones: application foundation, NetBox inventory, and read-only hardware inspection are in progress.

Workspace decision: there is one shared list of users, NetBox connections and profiles. Existing internal scope IDs are retained to preserve encrypted data; they are not user-facing environments. All users can see shared connections and published profiles, while NetBox keys and inspection evidence remain per-user. Full users manage shared credentials and profiles; readonly users cannot.

Workspace was documentation-only when implementation began; it is not currently a Git repository. There is no configured Git remote, so `forge` is a temporary Go module name. Mineral is available at `/Users/danil/Development/mineral` as `@mineral-ui/design` version 0.1.0.

Verified local tools: Go 1.26.3, Node 26.5.0, npm 11.17.0, macOS arm64.
